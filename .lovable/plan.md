

# Замінити модальне вікно замовлення на окрему сторінку

## Проблема
Модальне вікно з формою замовлення занадто довге і не скролиться на менших екранах — частина контенту обрізається.

## Рішення
Перетворити модальне вікно на окрему сторінку `/order`, яка відкривається в тому ж вікні (не в новій вкладці — щоб зберегти навігацію назад). Сторінка матиме той самий стиль, що й payment-success/payment-cancelled (навбар з логотипом + контент по центру), і буде нормально скролитися.

## Кроки

1. **Створити сторінку `src/pages/Order.tsx`**
   - Перенести всю логіку форми з `OrderModal.tsx` (стан, submit, Stripe/Telegram інтеграцію)
   - Приймати items через URL search params або React Router state
   - Навбар зверху (як на payment-success), форма скролиться нормально
   - Той самий візуальний стиль: bg-ink, cream текст, gold акценти, sharp corners

2. **Оновити `Products.tsx`**
   - Замість відкриття модалки — `navigate('/order', { state: { items, defaultPaymentMethod } })`
   - Прибрати імпорт і рендер `OrderModal`

3. **Додати роут `/order` в `App.tsx`**

4. **Видалити `OrderModal.tsx`** (більше не потрібен)

## Технічні деталі
- Дані товарів передаються через `useLocation().state` (React Router)
- Якщо state порожній (пряме відкриття URL) — редирект на головну
- Форма вільно скролиться на всіх розмірах екрану
