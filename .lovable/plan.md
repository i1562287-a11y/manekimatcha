

# Зберегти STRIPE_WEBHOOK_SECRET

Додам секрет `STRIPE_WEBHOOK_SECRET` через інструмент збереження секретів. Тебе попросять вставити значення ключа (починається з `whsec_...`).

## Крок
1. Викликати інструмент `add_secret` для `STRIPE_WEBHOOK_SECRET` — ти вставиш скопійований ключ у поле введення.

Після збереження вебхук буде верифікувати підписи від Stripe, і інтеграція буде повністю готова.
