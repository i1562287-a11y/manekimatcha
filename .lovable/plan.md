

## План: оновлення палітри кольорів

### Що змінюється

Замінити CSS-змінні в `src/index.css` (`:root` блок) на новий набір. Це автоматично прокотиться по всьому сайту через Tailwind токени (`bg-matcha`, `text-gold`, `bg-pale-matcha` тощо) — компоненти чіпати не треба.

### Превʼю змін

| Токен | Було | Стане | Де видно |
|-------|------|-------|----------|
| `--ink` | темно-зелений #1A2E1E | нейтральний темний #1A1F2B | Заголовки, текст, тёмні секції (Pricing, Why-comparison, TrustStrip) |
| `--matcha` | приглушений #2D6A4F | живий салатовий #7AAD44 | Кнопки CTA, акценти, Hero CTA, sticky CTA |
| `--gold` | теплий жовтий #C9A84C | **фіолетовий #8E6BC9** | Лейбли в темних секціях ("PRICING", "COMPARISON"), точки-роздільники в TrustStrip |
| `--pale-matcha` | бліда зелень | світліша салатова #EDF5E0 | Фон WhySection |
| `--batch-gold` | теплий бежевий | **світлий фіолет #F0ECFA** | Фон BatchBadge секції |
| `--fog` / `--mist` | сірі тони | зеленуваті сірі | Допоміжний текст, роздільники |
| `--cream` / `--white` | без змін | без змін | Основний фон |

### Як це виглядатиме (концептуально)

```text
Hero: cream фон → темний нейтральний текст → яскрава салатова кнопка
BatchBadge: ніжно-фіолетовий фон → салатовий progress bar
Pricing (темна): майже чорний фон → ФІОЛЕТОВИЙ лейбл "PRICING" + золоті іконки... 
   ↑ УВАГА: іконки в Pricing зараз `text-gold` → стануть фіолетовими
TrustStrip: чорна полоса → фіолетові крапки-роздільники
Why-comparison: чорний блок → ФІОЛЕТОВИЙ лейбл, салатові "так" значення
```

### Потенційні проблеми, на які варто звернути увагу

1. **Контраст фіолетового на темному фоні** (#8E6BC9 на #1A1F2B) — пройде WCAG AA для великого тексту, але дрібні mono-лейбли можуть виглядати трохи менш читабельно ніж золотий. Якщо не сподобається — підкажи, зробимо світліший фіолет (~70% lightness).

2. **Семантика "gold" → фіолетовий** — назва токена `--gold` залишиться, але колір буде фіолетовим. Це нормально для CSS (нікого не зламає), просто майте на увазі при майбутніх правках. Якщо хочеш — можемо перейменувати на `--accent` пізніше.

3. **Brand memory** — в `mem://index.md` зараз записано "gold #C9A84C". Оновлю memory на нові значення, щоб майбутні правки не повертали старі кольори.

4. **Емоційний зсув бренду** — поточна палітра тепла/традиційна (японська естетика з земляними тонами). Нова — холодніша/сучасніша (салатовий + фіолет — це більше "tech wellness"). Це усвідомлене рішення?
